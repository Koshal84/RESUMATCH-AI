# Relevance labels

For evaluation, create a local `relevance.csv` with columns:

`query_id,job_id,relevance`

Use an ordinal relevance scale such as 0 (not relevant), 1 (partially relevant), 2 (relevant), 3 (highly relevant). Write annotation guidelines before labeling and, where possible, have a second reviewer independently label a subset. Keep this file local unless redistribution is explicitly permitted.
