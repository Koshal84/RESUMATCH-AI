# Data governance

Before adding a public dataset:

- Record dataset name, source URL, version/date accessed, license, attribution, and permitted uses.
- Check whether the data contains personal information or scraped contact details.
- Do not commit resumes, names, email addresses, phone numbers, or other personal data.
- Do not assume public availability means permission to redistribute.
- Keep third-party dataset files out of Git by default.
- Use anonymized or consented resume examples for local testing.
- Document known sampling, geographic, language, and occupation biases.
- Do not use the system to make or automate real hiring decisions.
